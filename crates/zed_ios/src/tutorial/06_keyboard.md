# Hardware Keyboard Tips

Zed for iPad is designed first for an iPad with a hardware keyboard and trackpad.

## Recommended Setup

- Use landscape orientation when possible.
- Keep a trackpad or mouse connected for panel toggles and precise selection.
- Leave enough battery headroom for long sessions, especially if you are running tests or agent tasks.

## Useful Actions

- Command Palette: use your usual keyboard shortcut.
- File Finder: use the standard Zed action or keyboard shortcut.
- Project Search: use the standard workspace search flow and shortcuts.
- Terminal: open the standard terminal dock from the workspace.

## Workflow Advice

- Treat the iPad app like a remote cockpit, not a local laptop replacement.
- Keep one main editor pane and use panels aggressively instead of trying to juggle many floating surfaces.
- Reopen your last workspace when you return to the app to reduce connection setup time.
