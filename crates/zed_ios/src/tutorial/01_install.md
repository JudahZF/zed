# Install Zed on Your Remote Machine

To use Zed for iPad, you'll need Zed installed on your development machine (the computer you'll connect to).

## Download and Install

### macOS

1. Download Zed from [zed.dev](https://zed.dev)
2. Open the downloaded `.dmg` file
3. Drag Zed to your Applications folder
4. Open Zed once to complete the installation

### Linux

Install using the official script:

```bash
curl -f https://zed.dev/install.sh | sh
```

Or download from the [releases page](https://github.com/zed-industries/zed/releases) for your distribution.

## Verify Installation

Open a terminal on your remote machine and run:

```bash
zed --version
```

You should see the Zed version number printed.

## Next Steps

Once Zed is installed, you'll need to start the remote server so your iPad can connect to it.
